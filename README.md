## نظرة عامة

الغرض من هذا المستند هو تقديم المفاهيم الأساسية لـ **Spring MVC**، وهو إطار عمل ويب Java يعتمد على نموذج **MVC (Model–View–Controller)**، من خلال أمثلة توضيحية.

يعد Spring MVC جزءًا من نظام **Spring Framework** ويوفر إطار عمل منظم لتطوير تطبيقات ويب Java قوية وسهلة الإدارة.

يقدم هذا الدرس أيضًا **Thymeleaf**، وهو محرك عرض حديث وقوي يتكامل بشكل جيد للغاية مع Spring MVC.

## الجمهور المستهدف

هذا الدرس مخصص للقراء الذين يتمتعون **بإجادة جيدة للغة Java**.

**لا يتطلب الأمر أي معرفة مسبقة بالبرمجة على الويب**، حيث يتم تقديم المفاهيم بشكل تدريجي.

## نطاق الوثيقة

على الرغم من تفصيلها النسبي، لا تدعي هذه الوثيقة أنها شاملة.
Spring هو إطار عمل واسع النطاق، يتألف من العديد من المكونات والإضافات.

تم تصميم الوثيقة بحيث **يمكن قراءتها بدون جهاز كمبيوتر**، وهو ما يفسر وجود العديد من **لقطات الشاشة**.
