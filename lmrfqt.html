    9. المرفقات

    نقدم هنا كيفية تثبيت الأدوات المستخدمة في هذا المستند على أجهزة تعمل بنظام ويندوز 7 أو 8.

    9.1. تثبيت JDK

    يمكن العثور على URL و[http://www.oracle.com/technetwork/java/javase/downloads/index.html] (أكتوبر 2014)، وأحدث إصدار هو JDK. وسنسمي من الآن فصاعدًا مجلد تثبيت JDK بـ <jdk-install>.

     

    9.2. تثبيت Maven

    Maven هي أداة لإدارة تبعيات مشروع Java وأكثر من ذلك. وهي متوفرة في URL و[http://maven.apache.org/download.cgi].

     

    قم بتنزيل الملف المضغوط وفك ضغطه. سنطلق على مجلد تثبيت Maven اسم <maven-install>.

    • في [1]، يقوم الملف [conf / settings.xml] بتكوين Maven؛

    ويحتوي على الأسطر التالية:

    
  <!-- localRepository
   | The path to the local repository maven will use to store artifacts.
   |
   | Default: ${user.home}/.m2/repository
  <localRepository>/path/to/local/repo</localRepository>
-->

    قد تتسبب القيمة الافتراضية للسطر 4 في مشكلة لبعض البرامج، مثل {user.home}، إذا كان مسار {user.home} الخاص بك يحتوي على مسافة (على سبيل المثال [C:\Users\Serge Tahé])، بما في ذلك IntellijIDEA. في هذه الحالة، سنكتب شيئًا مثل:

    
  <!-- localRepository
   | The path to the local repository maven will use to store artifacts.
   |
   | Default: ${user.home}/.m2/repository
  <localRepository>/path/to/local/repo</localRepository>
  -->
<localRepository>D:\Programs\devjava\maven\.m2\repository</localRepository>

    ونتجنب، في السطر 7، استخدام مسار يحتوي على مسافات.

    9.7. إدارة jSON في Java

    بشكل شفاف بالنسبة للمطور، يستخدم إطار العمل [Spring MVC] مكتبة jSON [Jackson]. لتوضيح ماهية jSON (JavaScript Object Notation)، نقدم هنا برنامجًا يقوم بتسلسل الكائنات إلى jSON ويقوم بالعكس عن طريق فك تسلسل سلاسل jSON الناتجة لإعادة إنشاء الكائنات الأصلية.

    تسمح مكتبة «Jackson» بإنشاء:

    • سلسلة jSON لكائن: new ObjectMapper().writeValueAsString(object)؛
    • كائنًا من سلسلة jSON: new ObjectMapper().readValue(jsonString, Object.class).

    قد تؤدي كلتا الطريقتين إلى إثارة استثناء IOException. فيما يلي مثال على ذلك.

      

    المشروع أعلاه هو مشروع Maven يحتوي على الملف [pom.xml] التالي؛

    الفئة [Personne] هي كما يلي:

    
package istia.st.json;

public class Personne {
    // البيانات
    private String nom;
    private String prenom;
    private int age;

    // الشركات المصنعة
    public Personne() {

    }

    public Personne(String nom, String prénom, int âge) {
        this.nom = nom;
        this.prenom = prénom;
        this.age = âge;
    }

    // التوقيع
    public String toString() {
        return String.format("Personne[%s, %s, %d]", nom, prenom, age);
    }

    // المنشورات والمُعيّنات
...
}

    الفئة [Main] هي كما يلي:

    
package istia.st.json;

import com.fasterxml.jackson.databind.ObjectMapper;

import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

public class Main {
  // أداة التسلسل/إلغاء التسلسل
  static ObjectMapper mapper = new ObjectMapper();

  public static void main(String[] args) throws IOException {
    // إنشاء شخص
    Personne paul = new Personne("Denis", "Paul", 40);
    // العرض jSON
    String json = mapper.writeValueAsString(paul);
    System.out.println("Json=" + json);
    // إنشاء مثيل لـ Personne من Json
    Personne p = mapper.readValue(json, Personne.class);
    // عرض كائن «Personne»
    System.out.println("Personne=" + p);
    // مصفوفة
    Personne virginie = new Personne("Radot", "Virginie", 20);
    Personne[] personnes = new Personne[]{paul, virginie};
    // عرض JSON
    json = mapper.writeValueAsString(personnes);
    System.out.println("Json personnes=" + json);
    // قاموس
    Map<String, Personne> hpersonnes = new HashMap<String, Personne>();
    hpersonnes.put("1", paul);
    hpersonnes.put("2", virginie);
    // عرض JSON
    json = mapper.writeValueAsString(hpersonnes);
    System.out.println("Json hpersonnes=" + json);
  }
}

    من هذا المثال، نستخلص ما يلي:

    • الكائن [ObjectMapper] الضروري للتحويلات jSON / الكائن: السطر 11؛
    • التحويل [Personne] --> jSON: السطر 17؛
    • التحويل jSON --> [Personne]: السطر 20؛
    • الاستثناء [IOException] الذي أطلقته الطريقتان: السطر 13.

    9.8. تثبيت [Webstorm]

    [WebStorm] (WS) هو النسخة المطورة من IDE لـ JetBrains لتطوير تطبيقات HTML / CSS / JS. وقد وجدتُه مثاليًا لتطوير تطبيقات Angular. موقع التنزيل هو [http://www.jetbrains.com/webstorm/download/]. إنه برنامج مدفوع الثمن، لكن يمكن تنزيل نسخة تجريبية صالحة لمدة 30 يومًا. تتوفر نسخة شخصية ونسخة للطلاب بأسعار معقولة.

    لتثبيت مكتبات JS داخل أحد التطبيقات، يستخدم WS أداة تُسمى [bower]. هذه الأداة هي وحدة تابعة لـ [node.js]، وهي مجموعة من مكتبات JS. علاوة على ذلك، يتم البحث عن مكتبات JS على موقع Git، مما يتطلب وجود عميل Git على الجهاز الذي يقوم بالتنزيل.

    9.8.1. تثبيت [node.js]

    موقع تنزيل [node.js] هو [http://nodejs.org/]. قم بتنزيل برنامج التثبيت ثم قم بتشغيله. لا يوجد شيء آخر يجب القيام به في الوقت الحالي.
